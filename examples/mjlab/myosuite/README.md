# MyoSuite MyoChallenge Tasks

Source: https://github.com/ttktjmt/mjlab_myochallenge

Demo: WIP

## Prerequisites

The tasks live in `mjlab_myochallenge`, which registers them with mjlab on import. It is
not part of any mjswan extra — install it from its own repo:

```sh
uv pip install git+https://github.com/ttktjmt/mjlab_myochallenge.git
```

## Run

```sh
uv run python examples/mjlab/myosuite/main.py
```
