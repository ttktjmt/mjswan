# The cutter's test files

What `cut` in [../src/index.ts](../src/index.ts) returns for each file here, and what
mjswan's Python cutter must return too ([ADR 0017](../../../docs/adr/0017-assets-as-content-addressed-blobs.md)
§2.6). mjswan copies this directory into its tests, so a change here is made there too.

`vectors.json` lists the cases:

- `name`: the path the file is cut under. A name ending `.onnx`, in any case, is read as ONNX.
- `input`: the file's bytes, as parts joined in order. `{"file": "…"}` is a file in this
  directory. `{"xorshift32": seed, "size": n}` is `n` generated bytes, for what is over
  16 MiB: starting from `x = seed`, each step sets `x ^= x << 13`, `x ^= x >> 17`,
  `x ^= x << 5` on 32 bits, then adds `x` as four bytes little-endian; the last step is cut
  to `n`.
- `expect`: the file's entry in `files.json`.

`make.py` writes the `.onnx` inputs with onnx's own serializer and says what each one
checks. A case is added once two cutters written apart agree on it.
